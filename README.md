# 🐣 Simple Incubator

A lightweight Minecraft mod that introduces a single block: an **egg incubator**! Incubate **any vanilla egg** and customize hatching times and drop rates. Designed for simplicity and future expandability.

---

## 📦 Features

- Incubates **any** vanilla egg (yes, even dragon and turtle eggs).
- Fully configurable:
  - Time to hatch
  - Spawn egg drop chance
- No dependencies

Coming soon:
- Transmitter & Receiver system to control mob spawners remotely.

---

## 🔧 Configuration

After launching the game once with the mod installed, a config file will be generated where you can:

- Change the time required for an egg to hatch
- Set the rarity of mob spawn egg drops

## 📥 Installation

1. Download the `.jar` file from [CurseForge](https://www.curseforge.com/minecraft/mc-mods/simple-incubator).
2. Place it into your `minecraft/mods` folder.
3. Launch Minecraft with a compatible mod loader (e.g. NeoForge).
